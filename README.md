# 💱 FXFlow

**FXFlow** is a modern currency converter application built with React.

The project focuses on providing a simple, intuitive, and responsive interface for currency conversion while following modern frontend development practices.

## 🛠 Tech Stack

- React
- JavaScript (ES6+)
- Vite
- CSS3
